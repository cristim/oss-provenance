- 68 offline tests passed: 17 library, 16 workflow, 2 evidence, 14 Git snapshot, 16 notice, and 3 scanner tests.

## Limits of this verification

The hosted corpus is not exhaustive. A negative result does not prove original authorship. License rules and artifact-only obligation decisions require explicit maintainer review; the tool does not provide a universal legal compatibility decision.

Agent options currently produce a blocked, source-free handoff. Authenticated generation and enforced provider/test isolation have not been verified together; automatic rewrite and retry are not implemented. ScanCode report validation is supported, but automatic ScanCode execution is not implemented. The repository CI definition has not been run remotely, and consuming projects must configure their own protected policy and baseline. No package was published or hooks installed into another project.
