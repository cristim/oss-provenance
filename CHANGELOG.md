# Changelog

## 0.2.0 (unreleased)

- Rename the CLI and repository to ai-cleanroom while retaining historical policy paths, admission keys, and environment aliases.
- Apply notices for already admitted evidence directly to a verified index snapshot, preserving working-tree files.
- Generate Claude replacements in fresh Docker sessions, execute frozen trusted tests separately, rescan, and stage through a recoverable transaction. Persist a maximum of ten unsuccessful attempts across restarts.
- Start validated subsequent repair jobs after successful application, retaining immutable completion receipts, counts, sessions, and failed candidates.
- Pass provider credentials through bounded stdin and disable provider container logging so credentials stay out of Docker configuration and daemon logs.
- Compare snippet bytes exactly and support separately admitted modification hash pairs without changing notice identities.
- Collect immutable public GitLab evidence and run separately installed, version-pinned ScanCode as a proposal-only step.
- Coordinate scanner requests and durable cooldowns across processes. Bound opt-in cache storage while preserving unrelated files.
- Add dependency advisory/yank checks, trusted reusable provenance CI, authoritative merge verification, and native release archives with dependency notices and checksums.

## 0.1.0

- Add staged-source fingerprint scanning, explicit license policy admission, evidence collection, third-party notice proposals, and manual agent handoffs.
